## 1. 快速开始

### 1.1 下载脚本位置

项目根目录/scripts/download_models.sh

### 1.2 常用命令

```bash
下载所有模型和原生库（推荐首次使用）
./scripts/download_models.sh all
仅下载模型（不含原生库）
./scripts/download_models.sh models
仅下载原生库
./scripts/download_models.sh libs
查看当前下载状态
./scripts/download_models.sh status
清理所有已下载内容
./scripts/download_models.sh clean
指定平台下载（如部署到 Linux 服务器）
TARGET_PLATFORM=linux-x64 ./scripts/download_models.sh all
```

### 1.3 支持的平台

| 平台标识 | 操作系统 | CPU 架构 | 适用场景 |
|---------|---------|---------|---------|
| `linux-x64` | Linux | Intel/AMD 64位 | 大多数云服务器 |
| `linux-aarch64` | Linux | ARM 64位 | 树莓派、阿里云ARM服务器 |
| `osx-x86_64` | macOS | Intel芯片 | 旧款 Mac |
| `osx-arm64` | macOS | Apple Silicon (M1/M2/M3) | 新款 Mac |
| `win-x64` | Windows | 64位 | Windows 开发环境 |

> **自动检测**：脚本会自动检测当前操作系统和架构，无需手动指定。

### 2.2 VAD 语音检测模型 (Silero VAD)

#### 基本信息
- **文件名**: `silero_vad.onnx`
- **大小**: ~2.2MB
- **下载地址**: `https://github.com/snakers4/silero-vad/raw/master/src/silero_vad/data/silero_vad.onnx`
- **开源协议**: ✅ **MIT License**（最宽松的开源协议）
- **项目地址**: https://github.com/snakers4/silero-vad

#### 功能说明
**VAD (Voice Activity Detection)** 用于检测音频中是否有人说话，主要作用：
- 🎯 **节省资源**：无人说话时不进行语音识别
- 🎯 **提升体验**：避免背景噪音误触发
- 🎯 **实时响应**：快速判断说话开始/结束

#### 技术特点
- 基于 ONNX 格式，跨平台兼容
- 轻量级模型，推理速度快
- 准确率高，适合实时应用

#### 使用场景示例
用户："小智小智" ↓ VAD 检测到语音活动 ↓ 触发 STT 语音识别 识别结果："小智小智" ↓ 唤醒设备，开始对话

## 3. 原生库深度解析

### 3.1 什么是原生库？

#### 核心概念

**原生库（Native Libraries）** 是用 **C/C++** 等底层语言编译的二进制库文件，可以直接在操作系统层面运行。

#### 为什么需要原生库？

本项目涉及大量**语音信号处理**和**深度学习推理**，这些任务的特点：
- 🔢 **计算密集**：每秒数百万次浮点运算
- ⏱️ **实时性要求高**：延迟需控制在毫秒级
- 💾 **内存操作频繁**：音频数据的读写和处理

如果使用纯 Java 实现：
- ❌ 速度慢（JVM 虚拟机有性能开销）
- ❌ 内存占用高
- ❌ 难以利用 CPU 指令集优化（如 AVX、NEON）

而使用 C/C++ 原生库：
- ✅ **速度快 10-100 倍**
- ✅ **可直接调用硬件加速**
- ✅ **内存效率更高**
- ✅ **延迟更低**（适合实时语音交互）

### 3.3 sherpa-onnx JNI 库详解

#### 组成部分

##### 1. `libsherpa-onnx-jni.*` - JNI 桥接层
- **作用**：让 Java 代码能够调用 C++ 编写的 sherpa-onnx 引擎
- **技术**：JNI (Java Native Interface)
- **版本**：sherpa-onnx v1.12.23

##### 2. `libonnxruntime.*` - ONNX Runtime 推理引擎
- **开发者**：Microsoft（微软）
- **作用**：加载和运行 ONNX 格式的 AI 模型
- **版本**：v1.23.2
- **开源协议**：MIT License
- **项目地址**：https://github.com/microsoft/onnxruntime

#### 工作流程图
